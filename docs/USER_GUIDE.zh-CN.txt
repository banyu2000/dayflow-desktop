日常 DAYFLOW · 桌面日历、待办与长期目标 1.3
================================

一、打开就能用

1. 将压缩包“提取全部”到一个普通文件夹，不要在压缩包内直接运行。
2. 双击“日常日历.exe”。无需安装 Python、Node 或额外软件。
   适用于 Windows 10 / 11，需系统自带的 .NET Framework 4.8。
3. 点“桌面模式”切换成小组件；点“展开”返回完整月历。
4. 点“置顶”，让组件始终显示在其他窗口上方。模式与置顶设置会自动记住。
5. 需要桌面入口：右键 exe → 显示更多选项 → 发送到 → 桌面快捷方式。

这是独立的桌面浮动窗口，可移动、缩放与置顶。支持开机自启动与极简悬浮条。
拖动顶部品牌或标题空白区域可以移动窗口，双击该区域可最大化/还原。
右上角“−”最小化，“×”退出；也可通过更多菜单隐藏到托盘。
点击关闭会退出；要继续后台运行，请用“··· → 隐藏到系统托盘”。
双击任务栏右下角的日常图标可以重新打开；再次运行 exe 也会唤回已有窗口。

新增：开机自启动与极简悬浮条

在顶部点击“悬浮条”（紧凑窗口中为“◦”），或从“··· → 极简悬浮条”进入。
悬浮条默认约 324 × 84，始终置顶，不占用任务栏，沿用透明玻璃与柔和渐变。
每个小圆点代表一项日期为今天的待办（包含长期目标中的待办）：
  · 暗色空心点 = 未完成；亮色实心点 = 已完成。
  · “已完成数 / 总数”显示整体进度；鼠标停留可查看待办标题。
  · 点击圆点切换完成状态，自动保存，同时更新长期目标的进度。
  · 完成后圆点留在原位，给出 220ms 的轻微回弹反馈。
  · 无日期、过去或未来日期的待办不计入；跨日后自动更新（最多约 15 秒）。
  · 较多待办自动换行，最多显示四行，其余可滚动查看。
拖动顶部空白区域或左侧拖动标记移动，自动记住位置；显示器变化后会回到可见区域。
点“＋”添加今天的待办；点“↗”或双击顶部展开日历。
“···”可设置自启动、隐藏到托盘或退出。Alt+F4 关闭悬浮条会展开日历；退出请用菜单。
下次启动会恢复上次使用的悬浮条/日历模式；主窗口关闭仍为退出程序。

开启或关闭自启动：主窗口/悬浮条“··· → 开机自启动”，或右键系统托盘图标。
勾选表示已在当前用户的 Windows“启动”文件夹创建快捷方式，自启动在登录后执行，
无需管理员权限。开关状态来自 Windows 实际配置，数据备份不会替其他电脑开启自启动。
请将程序放在固定位置；移动整个程序文件夹后，在新位置重新开启一次自启动。
若 Windows 任务管理器另外禁用了该启动项，需要在“启动应用”里重新启用。
快捷方式名称为 DayFlowCalendar.lnk，可通过 Win+R 输入 shell:startup 查看。

新增：透明玻璃与渐变界面

使用半透明玻璃底板、白色高光描边、薄荷/冰蓝/淡紫柔和渐变与分层阴影。
Windows 11 22H2 及以上优先使用系统 Desktop Acrylic 背景；Windows 10 使用
兼容 Acrylic 背景。系统透明效果关闭或不可用时，使用渐变玻璃底板显示。
文字与控件保持完整的窗口不透明度，不通过整窗变淡实现透明。
实际桌面透出程度会随系统透明效果、窗口激活状态与后方内容而变化。

动效统一使用 cubic-bezier(.22,1,.36,1)，反馈在 150—280ms 内完成：
  · 按钮悬停 200ms，轻微浮起约 1.6px，并改变局部阴影。
  · 按下 150ms，轻压到 98.2%；松开/移开后 200—220ms 回到原位。
  · 目标卡片局部浮起约 2px，阴影变化 220ms。
  · 勾选待办后在原行位置出现 240ms 的柔和确认反馈。
  · 目标进度条 260ms 平滑更新；页面和新卡片以 260ms 轻微进入。
  · 勾选标记 160—180ms、标签页层级 200—220ms。
支持快速移入、按下再移开的动画中断，最终不会残留缩放或偏移。
系统关闭界面动画时，程序化位移动画会直接落到最终状态。

随附 PNG 预览来自应用实际绘制的透明界面图层，使用示例日程；
PNG 本身不包含 Windows 合成器提供的实时桌面模糊背景。

二、安排日程

点击月历中的日期，再点“＋ 日程”。双击日期也可直接新建。
填写名称、开始和结束日期/时间；时间使用 24 小时制，如 09:30。
支持跨天日程、全天日程、生活/工作/个人分类、地点、备注与提醒。
全天日程的“结束日期”包含当天，例如 11 月 18 日到 20 日共 3 天。
日历上的彩色实点表示日程，空心点表示当天还有未完成待办。
点击日程卡片即可编辑或删除；删除前会确认。

桌面提醒需要程序持续运行，隐藏到托盘也能提醒。
电脑关机或程序退出后，不会发出桌面提醒；系统通知设置也可能影响提示。
全天日程的提醒仅写入导出的日历文件，不发出桌面提示。
日程时间按此电脑的 Windows 时区解释，导出时转换为 UTC；全天日期保持原样。

三、待办清单

点击“＋ 待办”，填写内容，可选截止日期和重要标记。
勾选方框即可完成；“已完成”筛选中可以取消勾选恢复。
点击待办文字可以编辑或删除，点星号可切换重要标记。
支持未完成、今天、已完成、全部筛选，以及标题/备注搜索。
“今天”仅显示今天到期的未完成项；过去到期的条目在“未完成”中标记为逾期。
待办按重要标记与截止日期排序。清单与当天日程各自浏览。
紧凑模式用“日程 / 待办 / 长期目标”标签页切换。

新增：长期目标

切换到“长期目标”页面，点击“＋ 目标”，填写名称、说明和可选的目标日期。
保存后，在目标卡片内点击“＋ 添加待办”，可以加入任意多项步骤。
从目标中创建的待办默认不设截止日期，需要时可以自行勾选设置。

每张卡片都显示进度条、完成百分比和“已完成 / 总项数”。
例如 3 项完成 2 项显示 67%；全部完成后显示 100% 和“已达成”。
没有待办的目标显示 0%，不会误标记为已完成。
每项待办占相同权重；还有未完成项时最高显示 99%。
取消完成、添加待办、删除待办或调整所属目标，都会重新计算进度。

目标中的待办与原有待办清单是同一条记录，在任何一处勾选都会同步更新。
编辑现有待办，在“所属长期目标”中选择一个目标，即可将它归入目标；
选择“独立待办（不属于目标）”即可移出，内容与完成状态都会保留。
点击目标名称可编辑或删除目标；删除目标会保留全部待办，转为独立待办。
“展开 / 收起”可控制目标内的待办列表，方便同时查看多个目标。

桌面模式也有“长期目标”页；选中时会收起月历，为目标和进度留出空间。
日历导出可以照常导出有日期的目标待办；目标名称、进度和完成状态不会同步到 iPhone。

四、导入 iPhone 苹果日历

1. 点击“导入苹果日历”（紧凑模式中叫“导入 iPhone”）。
2. 选择范围：未来 90 天、全部日程，或当前选中日期。
3. 点击“导出 .ics 文件”并保存。
4. 通过你自己的邮箱，将该文件作为附件发给自己。
5. 在 iPhone 系统“邮件”App 中打开附件，选择“添加全部”或“添加到日历”，
   然后选择希望保存到的日历。不同 iOS 版本的按钮名称可能略有区别。
   如果从“文件”或聊天软件预览时没有添加按钮，请用系统“邮件”打开附件。

日程名称、起止时间、全天日期、地点、备注和提醒会写入文件。
可勾选“同时导出有日期的未完成待办”：这些待办会作为全天日程导入，
不会变成苹果“提醒事项”，其完成状态也不会同步。
无日期待办、已完成待办不会导出。

这是一次性文件导入，不是 iCloud 自动同步。
修改或删除电脑上的条目，不会自动修改手机上的内容。
尽量只导出新条目或需要的日期，避免反复导入同一批日程造成重复。
如果需要重新导入大量修改，建议在 iPhone 单独建立“日常”日历承接，
确认后再移除旧内容。程序不会替你发送邮件，也不读取任何苹果账号。

五、数据与备份

数据保存在 exe 所在文件夹的 data\calendar.json 中，每次操作自动保存。
目标、目标内待办以及完成状态也保存在这个文件中，备份时会一起保存。
data 文件夹在首次运行时自动创建；首次启动没有示例日程。
请将整个程序文件夹放在你有写入权限的位置，例如文档或桌面，
不要放到需要管理员权限的 Program Files 目录。
移动或备份时，保留整个文件夹，尤其是 data。

“··· → 备份全部数据”可导出包含日程、待办、长期目标和设置的 JSON 备份。
“··· → 从备份恢复”会验证文件，并在替换前先备份当前数据。
恢复数据会保留本机当前的窗口模式和置顶设置。
系统还会保留上一次保存版本 calendar.json.bak。
主文件损坏时优先恢复该版本，并保留损坏原文件；无法恢复时不会覆盖数据。

本工具不连接网络，不上传日程；数据未加密，请妥善保存本机文件与导出附件。

六、快捷键

Ctrl+N  新建日程
Ctrl+T  新建待办
Ctrl+E  导出苹果日历文件
Ctrl+G  新建长期目标

从旧版升级

先退出旧版程序。将新版 exe、ico 和说明文件复制到原文件夹并覆盖，
保留原来的 data 文件夹。不要用旧版 exe 再打开已升级的数据。
新版会自动读取 1.0 日程、待办和设置，首次读取时将原数据另存为
data\calendar.json.v1-backup，实际修改后使用新版数据格式保存。
旧版 JSON 备份仍可通过新版的“从备份恢复”读取。

七、源码与验证

“源码”文件夹包含完整 C# / WPF 源码与 build.ps1。
在该文件夹打开 PowerShell：
  powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
生成结果位于 build 文件夹。

开发检查命令（使用新的测试目录，不要指定真实 data 目录）：
  .\日常日历.exe --self-test --test-dir C:\你的测试目录
  .\日常日历.exe --ui-check --data-dir C:\你的测试目录\data

已验证本机保存/重读、数据回滚与损坏恢复、跨天/全天日期、UTF-8 中文、
RFC 5545 日历行折叠与转义、提醒导出，以及真实 WPF 控件的新增、编辑、
完成、筛选、搜索、置顶与模式切换；以及长期目标创建/编辑、多项待办、
清单与目标双向勾选、百分比、完成状态、成员调整、目标删除保留待办和旧版数据升级。
没有连接实体 iPhone 做导入实测，也未实现 iCloud、账号登录或双向同步。
